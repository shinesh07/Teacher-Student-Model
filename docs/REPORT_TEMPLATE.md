## 1. Problem definition and objectives

**Problem statement.** Given a 256 x 256 RGB flood-scene image, predict a binary mask
where 1 denotes flood water and 0 denotes non-flood using only hand-crafted pixel and
neighbourhood features.

**Users and deployment context.** `<e.g., emergency mapping / lightweight field device>`

**Scope and constraints.**

- Classical scikit-learn KNN, Random Forest, GaussianNB and K-Means only.
- No external data, neural networks, pretrained features, or test-informed tuning.
- The fixed RNG-42 split is retained exactly as prescribed.
- Students use at most six direct image-derived features and must meet their model
  capacity budget.

**Success criteria.** Primary metrics are micro-averaged flood-class F1 and IoU over
all 58 test images. Report model size, mean full-image segmentation time, retention,
compression, speed-up, and efficiency score Z where required.
